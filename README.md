# 🌤️ Weather App

A modern Weather Application built using **Flutter and Dart** that provides real-time weather information for different cities using the OpenWeather API.

## 📱 About the Project

This project was developed as part of my learning journey in Mobile Application Development. It helps users search for different cities and view their current weather conditions.

## ✨ Features

- 🔍 Search weather by city name.
- 🌡️ Real-time temperature updates.
- ☁️ Dynamic weather icons.
- 💧 Humidity information.
- 🌬️ Wind speed details.
- 🌡️ Feels-like temperature.
- 📊 Atmospheric pressure.
- 📱 Responsive user interface.

## 🛠️ Technologies Used

## ⚙️ How to Run the Project

1. Clone this repository.
2. Open the project in VS Code.
3. Run:

```bash
flutter pub get
```

4. Get your API key from OpenWeather.
5. Run the application using:

```bash
flutter run -d chrome --dart-define=OPENWEATHER_API_KEY=YOUR_API_KEY
```

Replace `YOUR_API_KEY` with your own API key.
